# OPTO-M · 통합 녹내장 관리 솔루션 (v2)

CNV Biotech의 스마트 안압계 **TONO-i CVT200** 연동 및 점안관리(IDROPM)를 통합한
녹내장 자가관리 앱 프로토타입입니다.

## v2 주요 특징
- **삼성헬스 스타일 홈 대시보드**: 오늘의 안압, 좌/우안 요약, 점안 준수율 링,
  걸음·수면·심박 타일, 오늘의 인사이트, 다음 알람을 한 화면에 표시
- **하단 4탭 내비게이션**: 홈 / 측정 / 리포트 / 전체
- **건강 리포트**: 주간·월간 토글, 직전 기간 대비 증감, 정상 상한선 표시 추이 차트
- **라이트 클리니컬 디자인 시스템 "Iris"**: 서지컬 틸(#0C8B99) 메인 컬러,
  Pretendard 서체, IOP 존 게이지 시그니처 컴포넌트
- 안압 측정/기록/분석/전송/알람 + 점안 + 생체신호 + 문진표(12문항) 전 기능 포함

## 실행 방법
```bash
npm install
npm run dev
```

## 기술 스택
- React 18 + Vite
- Tailwind CSS v4
- Recharts, Lucide React
